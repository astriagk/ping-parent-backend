# Auto-Generate API Documentation

## What This Does

Automatically generates **Postman Collection** and **Swagger/OpenAPI** documentation from your route files - no manual updates needed!

---

## How to Use

### One Command:
```bash
npm run docs:generate
```

### Output:
1. **Postman Collection**: `docs/v1/api/postman/collections/Ping_Parent_API_AutoGenerated.postman_collection.json`
2. **Swagger/OpenAPI**: `docs/v1/api/openapi/swagger_generated.json`

---

## What Gets Generated

### ✅ Postman Collection
- All endpoints (GET, POST, PUT, PATCH, DELETE)
- Authentication tokens (Parent/Driver/Admin)
- Path parameters (`:id`, `:studentId`, etc.)
- Request bodies for POST/PUT/PATCH
- Organized by route file

### ✅ Swagger/OpenAPI 3.0
- Complete OpenAPI 3.0 specification
- Interactive API documentation
- Security schemes
- Path parameters
- Request/response schemas
- Can be imported into Swagger UI, Postdoc, or any OpenAPI tool

---

## Import to Tools

### Postman:
1. Open Postman
2. Click **Import**
3. Select: `Ping_Parent_API_AutoGenerated.postman_collection.json`
4. Import environment: `Ping_Parent_Environment.postman_environment.json`

### Swagger UI:
1. Visit: https://editor.swagger.io/
2. File → Import file
3. Select: `swagger_generated.json`
4. View interactive docs

### VS Code (REST Client):
1. Install "REST Client" extension
2. Import `swagger_generated.json`
3. Test endpoints directly in VS Code

## Advanced: Integrate with CI/CD

Add to your CI/CD pipeline:

```yaml
# .github/workflows/docs.yml
name: Auto-Generate Docs

on:
  push:
    paths:
      - 'src/routes/**'

jobs:
  generate-docs:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - run: npm install
      - run: npm run docs:generate
      - run: git add docs/
      - run: git commit -m "Auto-update API docs"
      - run: git push
```

Now docs update automatically on every push!
