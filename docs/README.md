# Documentation Index

**Ping Parent** is a school transport management platform. Parents track their children's bus in real-time, drivers manage trips and attendance via QR/OTP verification, schools administer routes and students, and admins oversee the whole system. The backend is a Node.js/TypeScript/MongoDB API with Socket.IO for live GPS streaming.
