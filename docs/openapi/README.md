# OpenAPI / Swagger Specs

This folder contains all OpenAPI YAML files for Ping Parent backend APIs.

- **Latest version:** PP_API_V2_1_0_1.openapi.yaml
- **Version files:** .version.json, .version-v2.json

## How to Generate

Run:

    npm run docs:generate:v2 -- --bump=patch

## How to View

- Swagger UI is available at `/api-docs` when running the backend.
- Use Swagger Editor or Postman for local viewing.
